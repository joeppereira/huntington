# Files

- [ADR-PAY-017: Kafka as the Integration Backbone](adr-pay-017.md) - Accepted 2023-11-07 architecture decision making Kafka (Confluent) the mandatory integration backbone for payment lifecycle events across all payment systems at Crestline National Bank.
- [ADR-PAY-019: Event-Driven Channel Status (No Polling)](adr-pay-019.md) - Payments ARB decision (2024-06-11, accepted) that channel status integrations must consume Prism Payments Hub (PPH) lifecycle events rather than poll PPH, limiting synchronous status calls to throttled, user-initiated refresh; adopted after INC-2024-1182 and PIR-2024-07.
- [ADR-PAY-021: Hold Reason Confidentiality](adr-pay-021.md) - Accepted 2025-04-08 architecture decision requiring that payment hold reason codes, descriptions, scores, and analyst notes stay inside the financial-crimes trust boundary, with PPH v2 and payment events exposing only hold presence and holdId.
- [ADR-PAY-023: UETR as Canonical Correlation ID](adr-pay-023.md) - Payments ARB decision (2025-09-09, accepted) making UETR the canonical end-to-end correlation identifier for every outbound wire, assigned by PRISM Payments Hub (PPH) at release and available only to v2 API/event consumers, never to legacy v1 consumers.
- [ADR-PAY-026: Client-Facing Analytics Served via TDIP Insights API](adr-pay-026.md) - Payments ARB decision (2026-05-12) requiring that predictions, typical-time statistics and other analytical outputs shown to clients be computed in the Treasury Data & Insights Platform (TDIP) and served only through versioned TDIP Insights API endpoints, with channel BFFs forbidden from computing analytics and MRM classification mandatory before production use.
- [PNG-1544: gpi Batch Frequency Increase Declined](png-1544.md) - Payment Networks Engineering decision (2026-03-03, Addendum A to PNG-TDD-6.0) declining to raise the Swift gpi Tracker batch pull frequency from 4h to 2h because projected Tracker API usage would exceed the contracted monthly quota; recommended a change-feed-based internal service instead, which became GTSI-0107.
