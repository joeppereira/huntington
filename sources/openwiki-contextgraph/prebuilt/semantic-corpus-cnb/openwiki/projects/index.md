# Files

- [CBO-3120: Wire Status Lite Pilot](cbo-3120-wire-status-lite-pilot.md) - 2024 Crestline Business Online pilot that auto-refreshed wire status every 30 seconds from the PPH v1 synchronous status API for 60 clients, caused the month-end thread-pool exhaustion incident INC-2024-1182, and was terminated ("Won't Do"); the direct ancestor of ADR-PAY-019 and the CBO Status Projection Service.
- [CBO-3790: ACH Payment Tracker](cbo-3790-ach-payment-tracker.md) - Done epic (R25.4, 2025-11) that delivered ACH milestone tracking and status notifications in Crestline Business Online by building the reusable <cbo-journey-timeline> component and the Status Projection Service ACH consumer, now the reference pattern for event-driven status features including planned wire tracking.
- [CBO-4471: Migrate Wire Center from PPH v1 to PPH v2 APIs](cbo-4471-pph-v1-to-v2-migration.md) - Unscheduled 34-point epic to move cbo-wire-bff (SYS-CBO) off the deprecated PPH v1 Wire Status API onto PPH v2 (SYS-PPH) before the 2027-03-31 v1 sunset; blocked by the CES account-filter mapping story CBO-4473 and tracked jointly with the cross-consumer sunset epic PPH-2190.
- [ENS-1120: Entity-Level Subscriptions](ens-1120-entity-level-subscriptions.md) - Planned (2027-H1) Enterprise Notification Service initiative, owned by Melissa Grant, to let a user subscribe to a specific entity (e.g. one paymentId or caseId) rather than only to an event type with accountId/amount filters — the subscription-model gap a held-wire client-action notification would need, though not the only gap blocking one.
- [FCT-1951: Duplicate-Suspect Client Attestation Pilot](fct-1951-duplicate-suspect-attestation-pilot.md) - Done 2026-04 Financial Crimes Technology epic that piloted client attestation (via Service Center phone) to resolve HRC-01 duplicate-suspect payment holds faster, updated control CTRL-PAY-031 to permit digital-channel attestation for HRC-01 subject to step-up auth and a $5,000,000 Wire Room threshold, but left no digital-channel implementation in place.
- [GTSI-0107: gpi Tracker Real-Time Service (GTRS)](gtsi-0107-gpi-real-time-service.md) - Planned change-feed-based internal REST + event API over the Swift gpi Tracker, intended to let channels and other consumers obtain gpi status without quota-metered Swift Tracker API calls; not funded for 2026, with discovery targeted 2027-Q2 and build 2027-Q3/Q4, and currently blocked on sponsorship and an unapproved interim data-exposure path.
- [GTSI-0112: gpi Connector & Swift API Gateway Knowledge Transfer](gtsi-0112-gpi-knowledge-transfer.md) - In-progress epic (Jira GTSI-0112, target 2026-12-15) transferring operational ownership of the Swift Alliance & gpi Connector (SYS-PNG-GPI) and the Swift API gateway/SwiftNet PKI service accounts from Payment Networks Engineering to Global Transaction Services Integration, per CNB-MEMO-2026-09.
- [PPH-2190: PPH v1 API Sunset - Consumer Migration Tracking](pph-2190-v1-sunset-migration.md) - In-progress Jira epic (owner Kevin O'Brien) tracking the migration of all four PRISM Payments Hub (PPH) v1 API consumers ahead of the fixed, no-extension 2027-03-31 sunset confirmed by ARB on 2026-09-08, with cbo-wire-bff (CBO Wire Center) the sole consumer that has not started.
