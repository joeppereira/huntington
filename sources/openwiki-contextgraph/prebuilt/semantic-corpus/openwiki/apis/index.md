# Files

- [API-01 Accounts API](api-01-accounts-api.md) - Reference for the Accounts API (API-01, v3.4, base path /accounts/v3). It returns deposit, card and loan account details, balances and holders, and is the source of truth for balances shown in the mobile app and online banking.
- [API-02 Transactions API](api-02-transactions-api.md) - Reference for API-02 Transactions API (v3.1, base path /transactions/v3), which serves posted and pending transactions with merchant enrichment for deposit and card accounts. Covers owner, OAuth scopes, endpoints, limits, SLO, consumers and data lineage.
- [API-03 Payments Initiation API](api-03-payments-initiation-api.md) - Reference for the Payments Initiation API (API-03, v3.2, base path /payments/v3), which creates ACH, book transfer and check payments singly or in bulk, with ISO 20022 remittance and mandatory sanctions and fraud screening.
- [API-04 Real-Time Payments API](api-04-real-time-payments-api.md) - Reference for the Real-Time Payments API (API-04, v2.3, base path /rtp/v2), which sends instant, irrevocable account-to-account credit transfers and requests for payment 24x7x365 over real-time payment networks.
- [API-05 Wire Transfer API](api-05-wire-transfer-api.md) - Reference for the Wire Transfer API (API-05, v2.0, base path /wires/v2), which initiates domestic Fedwire and cross-border SWIFT wires with FX conversion from 60-second quotes and UETR-based tracking.
- [API-06 Card Management API](api-06-card-management-api.md) - Reference for the Card Management API (API-06, v2.6, base path /cards/v2), which manages debit and credit card status, spend controls and digital wallet provisioning using tokenized card references; raw PANs are never returned.
- [API-07 Customer Identity & KYC API](api-07-customer-identity-kyc-api.md) - Reference for the Customer Identity & KYC API (API-07, v1.9, base path /kyc/v1), which runs identity verification, due diligence and beneficial-ownership checks and returns a KYC status and AML risk rating that gate account opening and payment limits.
- [API-08 Fraud & Risk Signals API](api-08-fraud-risk-signals-api.md) - Reference for the Fraud Risk Signals API (API-08, v4.0, base path /fraud/v4), an internal-only real-time scoring service that returns a 0-1 fraud score, a decision and reason codes for card authorizations, payments and account events.
- [API-09 Credit Decisioning API](api-09-credit-decisioning-api.md) - Reference for the Credit Decisioning API (API-09, v2.2, base path /credit-decisions/v2), which returns approve/decline/refer decisions, credit line and pricing for consumer and small-business credit applications, and logs them for fair-lending monitoring and adverse-action notices.
- [API-10 Credit Risk Scoring API](api-10-credit-risk-scoring-api.md) - Internal-only, BCBS 239 critical data service (v3.0, /credit-risk/v3) that serves pool-level PD, LGD and related parameters; its point-in-time (PIT) endpoint is the PD/LGD input to the CECL model MDL-CR-007, and its through-the-cycle (TTC) endpoint serves Advanced approaches capital.
- [API-11 Loan Servicing API](api-11-loan-servicing-api.md) - Loan-level and portfolio-level balances, amortization schedules, delinquency, remaining contractual life and repricing terms for consumer and wholesale loans. A critical data service that feeds CECL exposure at default (EAD) and remaining life, and the ALM repricing profile.
- [API-12 Market Data API](api-12-market-data-api.md) - Critical data service (v5.1, /market-data/v5) publishing prices, yield curves, credit spreads and volatility surfaces; golden source for VaR, fair value and the policy rate and curves feeding the NII Sensitivity Model (MDL-ALM-014).
- [API-13 FX Rates API](api-13-fx-rates-api.md) - Reference for the FX Rates API (API-13, v2.4, base path /fx/v2), which serves spot, end-of-day and executable FX rates and quotes, owned by Market Data Services. Covers endpoints, scopes, limits, SLOs, lineage and documented gaps.
- [API-14 Macroeconomic Scenario API](api-14-macroeconomic-scenario-api.md) - Internal-only read API (v1.6, /scenarios/v1) that distributes Scenario Committee-approved, versioned and locked macroeconomic scenario sets, their probability weights and quarterly variable paths. It is the scenario source for the CECL allowance model (MDL-CR-007) and the capital planning and stress projection model (MDL-CAP-003).
- [API-15 Treasury Liquidity Positions API](api-15-treasury-liquidity-positions-api.md) - Internal-only, read-only Treasury data service (v2.1, base path /treasury/v2, owned by Treasury Technology) that publishes intraday cash, HQLA and rate-sensitive balance sheet positions by legal entity. It is the upstream feed for the NII Sensitivity Model (MDL-ALM-014), the Capital Planning model (MDL-CAP-003), the LCR and NSFR calculators and the liquidity stress testing engine.
- [API-16 Regulatory Reporting API](api-16-regulatory-reporting-api.md) - API-16 (v1.8, base path /regulatory/v1, owned by Finance Technology) serves governed regulatory capital, RWA, leverage exposure and FR Y-9C / FFIEC 101 / FR Y-15 line items, reconciled to the general ledger, and is the golden source for Pillar 3. This page covers its contract, scopes, consumers, lineage and the reports and metrics it supports.
- [API-17 Statements & Documents API](api-17-statements-documents-api.md) - Reference for the Statements & Documents API (API-17, v1.4, base path /documents/v1). It lists account statements by period, serves statements, tax forms and notices as PDF, and stores paperless (e-delivery) preferences.
- [API-18 Webhooks & Event Notifications API](api-18-webhooks-event-notifications-api.md) - Reference for the Webhooks & Event Notifications API (API-18, v1.3, base path /events/v1). It lets clients subscribe to signed HTTPS webhook events from payments and card systems, list recent events for replay, and send test events.
- [Developer Platform API Reference Overview](developer-platform-overview.md) - Platform-wide conventions for the Meridian Harbor Developer Platform (OAuth 2.0 auth, versioning, rate limits, idempotency, errors, environments, SLOs), the BCBS 239 critical data services, and an index of all 18 APIs by owner, consumer model and Tier 1 model feed.
