# Files

- [Internal Severely Adverse Scenario](internal-severely-adverse.md) - The firm's internally developed severely adverse macroeconomic and market scenario (set SA-2025-INT), distributed by the Macroeconomic Scenario API and used by the Capital Planning & Stress Projection Model (MDL-CAP-003) to project a minimum stressed CET1 ratio of 12.90% and an indicative stress capital buffer.
- [Macro Scenarios MSC-2025Q4 (Upside / Baseline / Downside)](macro-scenarios-msc-2025q4.md) - The MSC-2025Q4 macroeconomic scenario set (Upside 0.20, Baseline 0.50, Downside 0.30) approved 2025-12-15, its variable values, how API-14 serves it, and how the CECL model (MDL-CR-007) turns it into the 15,920 $mm year-end allowance.
- [Parallel Rate Shocks](parallel-rate-shocks.md) - The five-point parallel rate shock grid (-200, -100, 0, +100, +200 bp) used by the NII Sensitivity Model (MDL-ALM-014) for IRRBB, with its NII and EVE results, Board limit tests and known limitations.
